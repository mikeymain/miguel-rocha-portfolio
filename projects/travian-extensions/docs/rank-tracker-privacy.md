# Travian Rank Tracker privacy policy

Effective November 21, 2026.

Rank Tracker is an unofficial extension that displays your Travian: Legends rankings and history. When you open it or visit supported statistics pages, it reads rankings and game statistics such as population, production, culture points, military strength and raiding results. It uses the active tab address to identify the game world and can use your existing Travian session to request statistics from that world. To estimate when you joined a game world, it reads the date of the oldest Travian system message from your inbox listing. It saves the date and does not save message contents or login credentials.

Rankings, statistics, game-world addresses, timestamps and display preferences are stored locally in your browser. The extension sends requests only to supported Travian sites and does not transmit your saved history to the developer or an analytics service. The developer does not sell user data, use it for advertising or credit decisions, or transfer it to third parties.

You can export your saved data as a JSON backup or restore it from a file you choose. Uninstalling the extension removes its browser storage. Exported backups remain wherever you saved them until you delete them.

Rank Tracker uses data only to provide its ranking and history features, in accordance with the Chrome Web Store User Data Policy and its Limited Use requirements.

For privacy questions, use the publisher contact shown in the Chrome Web Store listing.
