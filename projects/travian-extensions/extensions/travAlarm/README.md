# TravAlarm

Get incoming attack alerts and see building, troop training, and research timers in one Travian dashboard. Set custom reminders and choose which categories play sounds.

**Version 3.57 · JavaScript · Manifest V3**

[Usage guide](../../docs/USAGE.md#travalarm) · [Installation](../../README.md#install-in-brave-chrome-or-edge) · [All extensions](../../README.md)

Load this directory with **Load unpacked** in a desktop Chromium browser. No build step is required. Refresh the game page after installation or updates.
