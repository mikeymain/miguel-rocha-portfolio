# Oasis Finder

Scores nearby oases using observed game data, troop costs and travel estimates.

**Version 70.11 · JavaScript · Manifest V3**

[Usage guide](../../docs/USAGE.md#oasis-finder) · [Installation](../../README.md#install-in-brave-chrome-or-edge) · [All extensions](../../README.md)

Use **Load unpacked** in Brave, Chrome, or Edge. In Firefox, use [Load Temporary Add-on](../../README.md#install-in-firefox). No build step is required. Refresh the game page after installation or updates.
