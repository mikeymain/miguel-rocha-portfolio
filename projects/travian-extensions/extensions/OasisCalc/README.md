# Oasis Finder

Scores nearby oases using observed game data, troop costs and travel estimates.

The rally point farm list shows saved animal counts with species icons beneath each oasis. Select **Inf def** or **Cav def** to sort by defence against that attacker type.

**Units needed** estimates the animals and defence at arrival, then shows the recommended troop count, expected losses, travel time and net resources. Set **Troop loss tolerance** in the Troops tab.

**Version 70.35 · JavaScript · Manifest V3**
