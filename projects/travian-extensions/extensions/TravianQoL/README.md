# Travian QoL

Configurable interface tools for farm lists, reports, resource calculations and village tasks.

**Version 1.6.13 · JavaScript · Manifest V3**

[Usage guide](../../docs/USAGE.md#travian-qol) · [Installation](../../README.md#install-in-brave-chrome-or-edge) · [All extensions](../../README.md)

Use **Load unpacked** in Brave, Chrome, or Edge. In Firefox, use [Load Temporary Add-on](../../README.md#install-in-firefox). No build step is required. Refresh the game page after installation or updates.
