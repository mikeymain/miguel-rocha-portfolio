# Travian Dark Mode

Adds a persistent dark theme and configurable button colours to Travian pages. Night-time assets for villages and resource fields are enabled by default and can be turned off in the toolbar popup.

**Version 2.7.4 · JavaScript · Manifest V3**

[Usage guide](../../docs/USAGE.md#travian-dark-mode) · [Installation](../../README.md#installing) · [All extensions](../../README.md)

Load this directory with **Load unpacked** in a desktop Chromium browser. No build step is required. Refresh the game page after installation or updates.
