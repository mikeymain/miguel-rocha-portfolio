# Travian Dark Mod

Adds a persistent dark theme and configurable button colours to Travian pages.

**Version 2.7.3 · JavaScript · Manifest V3**

[Usage guide](../../docs/USAGE.md#night-mode) · [Installation](../../README.md#install-in-brave-chrome-or-edge) · [All extensions](../../README.md)

Use **Load unpacked** in Brave, Chrome, or Edge. In Firefox, use [Load Temporary Add-on](../../README.md#install-in-firefox). No build step is required. Refresh the game page after installation or updates.
