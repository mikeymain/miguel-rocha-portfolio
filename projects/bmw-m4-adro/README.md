# BMW M4 ADRO Kit

A co-created vehicle modification for Forza Horizon 6, published on [Nexus Mods](https://www.nexusmods.com/forzahorizon6/mods/469).

**Primary tool:** Blender. **Skills:** 3D modelling, vehicle modification and preparing in-game releases.

## Project scope

- Widebody and standard-body variants.
- Custom exterior parts and interior styling.
- In-game colour options.

Blender was the main tool used for the modelling work. This is a collaborative project; the portfolio does not claim sole authorship of every asset.

## Release files

The supplied upload folder contains packaged ZIP releases, including `widebody.zip` and `non widebody.zip`, and nested copies of the vehicle archives. [releases.json](releases.json) records the two top-level packages, their sizes and SHA-256 hashes.

Download the published mod and follow its installation instructions on Nexus Mods. Large vehicle packages and duplicate archives are not checked into this source repository. No editable Blender source file was present in the supplied upload folder.
