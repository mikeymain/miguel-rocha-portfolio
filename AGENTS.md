# Travian extension publication

Every Travian extension change must **ALWAYS** be committed and pushed to `projects/travian-extensions` in this repository (https://github.com/mikeywikey-coding/miguel-rocha-portfolio/tree/main/projects/travian-extensions). That folder is the public distribution. Keep installed development and public runtime files synchronized, update affected guides and screenshots, and verify the push before reporting completion. Report blockers explicitly. This is standing user authorization to publish requested extension changes.

Bumping a manifest version on `main` publishes a release zip (`.github/workflows/release.yml`). Keep changes small and text objective. Do not run tests unless the user requests them.
