# Travian extension publication

Every Travian extension change must **ALWAYS** be committed and pushed to https://github.com/mikeywikey-coding/travian-extensions. Keep installed development and public runtime files synchronized, update affected guides and screenshots, and verify the push before reporting completion. Report blockers explicitly. This is standing user authorization to publish requested extension changes.

This portfolio links to the public Travian repository. Do not add copied extension sources here. Keep changes small and text objective. Do not run tests unless the user requests them.
