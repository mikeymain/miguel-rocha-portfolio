This portfolio collects personal and collaborative projects. Third-party code, data, images, fonts, sounds and game assets retain their original ownership and applicable terms. No repository-wide licence is granted over those materials.

- **Build Lab:** rule datasets from `lightmatmul/nba2k27-builder-dataset`, with provenance recorded in the retained dataset README and source modules. Additional game-related reference data and artwork came from the original project research. React, Vite, Phosphor icons, Inter and other npm dependencies keep their own licences. See the lockfile and upstream packages.
- **Workout Tracker:** exercise photographs originate from [free-exercise-db](https://github.com/yuhonas/free-exercise-db), as recorded in the original app documentation. External exercise videos remain hosted by their creators.
- **Travian extensions:** independent personal tools for Travian. Game names, imagery and any bundled third-party materials are not claimed as original portfolio assets.

The repository is private initially. Review the redistribution terms for bundled third-party material before changing its visibility or adding a public open-source licence.
